## Companies Table

```php
global $wpdb;

$charset_collate = $wpdb->get_charset_collate();

$companies_table = $wpdb->prefix . 'bill_manager_companies';

$sql = "CREATE TABLE {$companies_table} (
    ID bigint(20) unsigned NOT NULL AUTO_INCREMENT,
    user_id bigint(20) unsigned NOT NULL DEFAULT 0,
    ip varchar(45) NOT NULL,
    user_agent text NOT NULL,

    title varchar(255) NOT NULL,
    address text NULL,
    phone varchar(50) NULL,
    email varchar(255) NULL,

    opening_balance decimal(12,2) NOT NULL DEFAULT 0.00,
    balance_type enum('debit','credit') NOT NULL DEFAULT 'debit',

    notes text NULL,
    status tinyint(1) NOT NULL DEFAULT 1,

    created_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    PRIMARY KEY (ID),

    KEY user_id (user_id),
    KEY title (title),
    KEY status (status)

) {$charset_collate};";
```

## One additional recommendation

Instead of using `enum` columns (e.g., `bill_type`, `payment_method`, `balance_type`), I recommend using `VARCHAR` columns with validation in your PHP code. While `ENUM` works in MySQL, it makes future changes (such as adding a new payment method like `card` or `paypal`) require a database migration. A `VARCHAR(20)` or `VARCHAR(30)` column is more flexible and is commonly preferred in WordPress plugin development.

This schema is a solid foundation for a billing system that can later grow into a complete inventory, purchase, and sales management solution without major database redesign.
